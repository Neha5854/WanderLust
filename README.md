# WanderLust   https://wanderlust-2-0xv8.onrender.com/
WanderLust is a **feature-rich Airbnb-inspired** web platform that allows users to **list, discover, and book unique stays worldwide**. Built using **Node.js, Express.js, MongoDB, and EJS**, it ensures a **secure and seamless** experience for travelers and hosts alike. 

### ✨ **Key Features:** 
✅ **User Authentication** – Secure login & signup 
✅ **CRUD Operations** – Add, edit, and delete property listings & reviews 
✅ **Image Uploads** – Cloudinary integration for media storage 
✅ **Map Integration** – Interactive maps using Mapbox 
✅ **Responsive Design** – Optimized for all devices 

🚀 **Tech Stack:** Node.js | Express.js | MongoDB | Passport.js | Mapbox | Cloudinary | Bootstrap
